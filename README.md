**Aether Bastion: Solar Citadel** — Three.js 3D sunlit orbital bastion & tactical twin-stick wave defense playable offline in any desktop browser. Pilot the Aether Interceptor, harness the sweeping Golden Sun to refract amplified Solar Laser Links across Prism Pylons and Prism Mirror Spires, deploy tactical turrets (`[1]` Prism Spire, `[2]` Tesla Arc Tower, `[3]` Cryo Ward), trigger Phase Dash & Solar EMP Nova, unlock 10 stackable upgrades + 4 Relic Synergies, and defeat 6 hostile archetypes plus the 3-phase **Archon Sovereign** dreadnought.

## Controls

- `WASD` / `Arrow Keys`: Move · `Mouse`: 3D Aim · `LMB` / `F`: Fire / Auto-Fire
- `Space`: Phase Dash · `Q` / `RMB`: Solar EMP Nova · `1` / `2` / `3`: Deploy/Upgrade Turret (or pick Relic Evolution)
- `H`: Tactical Guide · `P` / `Esc`: Pause · `M`: Mute · `R`: Restart

## Run it

```sh
node serve.ts
```
